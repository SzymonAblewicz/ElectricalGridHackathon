Shift Factor Explorer — with overlap

Everything the basic viewer has, plus the overlap question: a node with a moderate shift factor on several congested branches can be worth more than one with a large factor on a single branch. Scores are computed live, so moving the threshold slider re-draws the whole ranking. Showing sensitivity by default — positive means curtailing there unloads the branch. Curtailing also worsens every branch where sensitivity is negative, so the headline score is net signed relief, not a count.
